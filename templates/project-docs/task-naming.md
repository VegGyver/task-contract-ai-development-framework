# Task Naming

## Existing convention

```txt
Primary format:
Examples:
External tracker:
Sub-step format:
Change request format:
Bug-fix format:
Extension format:
Refactor format:
Commit reference format:
```

## Rules

- Use existing team or tracker IDs when present.
- Do not rename or reuse historical task IDs.
- Keep task ID, task title, and framework task type as separate concepts.
- Create later extensions, fixes, refactors, and follow-up work as new linked tasks.
- Follow only an approved linked-task naming convention.
- If no linked-task convention is verified, record it as unclear; do not invent one.
