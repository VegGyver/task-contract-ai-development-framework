# Changelog

## v0.3.0 — Architecture A universal runtime

- Started exclusively from the valid v0.2.7 calibrated core; v0.2.8 remains discarded.
- Added one installed, versioned runtime outside target projects.
- Added the Universal Run Protocol for bootstrap, adoption, daily tasks and future agents.
- Added central agent, adapter and project-schema registries.
- Added deterministic machine-readable manifests with exact module paths and public optional selectors.
- Added exactly-one-target binding for directories, planned greenfield paths, files, archives and compatible host resources.
- Added automatic adapter selection and a strict adapter contract.
- Added the reference `tcaf` runner, installer, launcher, version activation and diagnostics.
- Added automatic validation for versions, registries, manifests, module boundaries, adapters, templates and target documentation.
- Removed multi-root and manual-bundle use from the standard procedures.
- Replaced divergent legacy agent copies with unregistered pointers to canonical operations.
- Strengthened repository-evidence extraction with explicit standard classifications and representative evidence.
- Formalized local-pattern-first and official-version-compatible implementation guidance.
- Kept model-facing runtime rules compact and core/tool separation explicit.
- Added machine-readable external role mappings and validation against parallel task-state sources.
- Added Project Brief open-decision presence and duplicate validation.
- Registered Cline `manual-envelope` transport, one-write task segmentation and `Pending` recovery while native invocation remains unverified.
- Tightened generated rules around verified capabilities, explicit `REFACTOR`, `DEVELOPER_RUN` checks and one operational status source.
- Added clean bootstrap and fixture-preflight acceptance requirements.
- Hardened Cline inspection with existence checks before reads, relevant dot-config discovery and isolated-legacy classification.

## v0.2.7 — Adoption document generation calibration

- Kept runtime and bundle growth minimal.
