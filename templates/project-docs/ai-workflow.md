# AI-Assisted Workflow

- Use compact project rules and bounded task contracts.
- Execute one approved step at a time.
- Preserve existing working code and capabilities.
- Use one approved operational task-state source; do not maintain parallel status sources.
- Require an explicit `REFACTOR` task for restructuring.
- Default checks are developer-run.
- Developer reviews, verifies, accepts and commits.
- Completed task history is append-only.
